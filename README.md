Vice Cover Studio — turn your own photos and a caption into GTA-style multi-panel cover art, exported as a PNG to share. Pick a layout (Hero, Duo, Trio or Quad), drop a photo into each panel, crop and pan it, choose a sunset or neon colour grade, write your title, and export in 1080 x 1080, 1080 x 1350 or 1920 x 1080. Everything runs offline in the browser: static files only, no build step, no network requests, no Rockstar logos, artwork or fonts — the lettering is drawn with system fonts and the two sample photos were made with an image model.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080, add your photos, and hit Export PNG.
